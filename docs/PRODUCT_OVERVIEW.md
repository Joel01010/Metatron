# Metatron product overview

Metatron is a local-first Windows assistant whose certified core is **dictation + presence + memory governance + accelerator truthfulness**. The product deliberately does not define success as “many integrations.” It defines success as fast, private, predictable daily voice input that uses local hardware honestly and stays inside a measurable resource envelope.

## Certified core

1. Dictation with explicit NPU → GPU → CPU routing.
2. Reactive pale-red / golden procedural presence.
3. Strict memory governor and disposable ML workers.
4. Separate reported states for detected, routable, selected, session-created and actual placement.

## Product layer

- first-run setup/diagnostics with Orb / Pets / Both choice;
- searchable local history (off by default);
- personal dictionary;
- per-app formatting/privacy rules;
- model/runtime readiness center;
- voice/TTS controls;
- configurable Solar/Lattice/Reactor animated core;
- up to four original procedural companions with independent behaviors and adaptive performance;
- searchable settings and Windows tray recovery;
- Kanban + interval schedules + approvals + explicit agent-run history/control;
- hardware truth and memory metrics;
- Ctrl+K command palette;
- privacy-conscious support bundle and full-system validator.

## Experimental layer

Agent adapters and S1-mini semantic cleanup stay experimental until their upstream protocols/licensing/hardware behavior have independent qualification. The local scheduler/Automation Center is productized as persistence and control UI, but **agent execution itself remains adapter-dependent and explicit**. No schedule silently launches an agent. Experimental integrations must never weaken the certified core's placement, privacy or memory claims.
