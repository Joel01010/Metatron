# Metatron v1.4.0 — Re-verification fixes

This source incorporates the issues found by the Windows re-verification of the original v1.4 package.

## Corrected deterministic regressions

1. **pytest temp root** — pytest now uses the checkout-local `.pytest-tmp` directory with failed-only retention. This avoids a stale locked `%TEMP%\pytest-of-*` tree without hard-coding a drive letter into the open-source package. The full Windows validator also supplies a unique output-directory `--basetemp` for each run.
2. **`Measure-MetatronDesktop.ps1` parse error** — the script was rewritten into balanced, readable PowerShell and now includes before/after system-memory and commit deltas.
3. **Rust formatting** — `src-tauri/build.rs` and `src-tauri/src/main.rs` were normalized to rustfmt-style formatting. Windows CI still runs `cargo fmt -- --check`; that native gate remains authoritative.
4. **v1.4 wrapper forwarding** — malformed `Test-Path` expressions were fixed and qualification arguments now use PowerShell hashtable splatting, avoiding the positional binding failure seen with array splatting on Windows PowerShell 5.1 and PowerShell 7.

## Corrected behavioral issues

- **SAPI interruption** now uses asynchronous `winsound.PlaySound(..., SND_ASYNC)` and a stop call. Qualification requires stop latency under 2 seconds and verifies the test ends well before the source clip could naturally finish. The same asynchronous pattern is used in the production TTS playback path.
- **Soak execution** is independent of unrelated validation failures; if a soak was requested, it runs and leaves evidence even when another gate fails.
- **Missing external speech sidecar** is a SKIP by default. It becomes a FAIL only with `-RequireSpeechRuntime`. Microphone and upstream EZSTT qualification remain separate evidence.
- **Process-tree memory accounting** refuses partial totals. Learned Windows worker charges prefer complete-tree private commit, then complete-tree working set.
- **Diagnostics** include handles, threads, process churn, sample overhead, system commit percentage and bounded GPU polling.

## Required Windows evidence after installing this source

Run `scripts\Invoke-MetatronV14Qualification.ps1` on the reference PC. The native run should regenerate PowerShell parser, `cargo fmt`, `cargo check`, Tauri build, orb, NPU/GPU/CPU, microphone, TTS interruption, installer/signature, and soak evidence from this exact corrected tree.
